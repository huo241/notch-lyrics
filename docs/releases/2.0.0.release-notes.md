## Notch Lyrics 2.0.0

版本号跳这么大，是因为这一版**删掉的东西不少**，而且**设置窗口整个重做了一遍**。  
删，也算一次大版本。

### 🎛 刘海里多了一块「统计」

CPU、GPU、内存、磁盘四个环；下面一条 60 秒的网络吞吐曲线（下载是实心、上传是细线），
底部是当前上下行速率和显存占用。采样只在你看它的时候跑——一个会出现在自己 CPU 读数里的
监控面板，是唯一值得设计去避免的失败模式。

- 配色四选一：单色 / 负载 / 温度 / 告警。默认单色。因为「红环 + GPU 100%」会让人以为
  机器出事了，而 GPU 那个数字其实只是「这一秒它有活干」——所以它**永远不上色**。
- 温度多高算高、磁盘多满算满，可以自己定阈值（设置 › 统计 › 告警）。
- 曲线的量程走固定阶梯，只在流量跨档时才变——按窗口峰值自动缩放会让整条线每秒重标一次，
  看起来在抖。

### ⚡ 歌词：抓得到的更快，抓不到的说清楚

以前的失败几乎都是同一个形状：**单次请求超时 10 秒，而整轮预算只有 6 秒**。于是一个慢请求
就把预算吃光，另一家源连试都没试。日志里那句「请求超时 → 未找到歌词」就是这么来的。

现在：

- **两家源并发**问，谁先给出结论就用谁。总耗时是两者的较大值，而不是和。
- **3 秒硬上限**，而且是真硬：`URLRequest` 的超时只管「连上以后等数据」，
  DNS 或握手卡住时形同虚设（实测能把设成 2.5 秒的请求拖到 4.5 秒才失败），
  所以到点由我们自己取消。
- **查不到不再进缓存**。以前一次超时会变成整场会话的「未找到」——同一首歌再点开也不重试。
- **关键词搜索留了一秒预算**。以前脏元数据（带后缀、带 feat.、现场版）会把 3 秒全花在
  精确匹配上，等轮到搜索时预算已经用光——而搜索恰恰是这些歌唯一的出路。
- **端点和代理可以自己填**（设置 › 媒体 › 歌词服务）。官方地址打不通时指一个镜像就行；
  代理留空则沿用系统。

顺手修了一个会给你**别人的歌词**的毛病：《Mesmer》会被《Mesmerizer》蹭到 0.85 分。
根子在标题只占一半权重——歌手和时长一对上，标题再离谱也能凑到 0.6 的及格线，所以光把
相似度压低没用（压到 0.6 还是 0.8 分）。现在标题得自己先过线，过不了整条作废；片段
包含也不再算同一首歌。

### 🎹 纯音乐，判定更硬

1.2.1 就认纯音乐，但只认「歌名里写着」的。像《18 Pieces, Op. 72》《Lydian Harp》
《Für Alina》这种标题里一点线索都没有的钢琴曲，还是掉回「未找到歌词」。

现在多两路证据：**编目号**（`Op. 72`、`BWV 846`、`K. 485`、`D. 899` 这些本身就说明
「这是一部作品，没有词」）和**流派**（所有源都空了之后，问一句 Apple Music 这首的流派，
`Classical` 直接就是结论）。刻意不收 Jazz / Electronic / Opera——这三个里带人声的太常见，
判成「纯音乐」比「未找到」更糟。

### 🖥 设置窗口按「系统设置」重做

- 每页顶部是图标 + 标题 + 一句话说明的居中卡片；每行左侧有图标方块；分隔线从**文字起点**
  开始，而不是压在图标底下——和 macOS「系统设置」同一套语法。
- 文案重写了一遍，删掉「Beyond the microphone:」这类一句正事没有的引导词，
  一律写成第一眼就能看懂的话。
- 顺手删了三个**点了什么都不会发生**的开关：手势页那个永远灰着的「横向手势切歌（尚未实现）」、
  高级页的「扩大悬停区域」、文件架页的「有文件时默认打开文件架」。它们要读的地方从来不存在。
- 同一个板块现在只有一个名字和一个图标。以前侧边栏叫「媒体」、标签栏叫「音乐」，
  而且两边图标还不一样。

### 🗂 想留哪块，自己挑

设置 › 外观 › 「标签」：媒体、文件架、速记、天气、统计，各一个开关。

关掉只是把它从刘海移走——功能、设置、数据原样保留，重新打开就是你离开时的样子。
至少会留一个（会隐藏最后一个的开关是禁用的）；要是你把「主页」指向的板块关掉了，
主页会自动挪到第一个还开着的。

### 🧹 删掉的

- **摄像头镜像和闲时表情动画**（原项目带过来的「附加功能」）。它和「把正在听的这首歌显示
  清楚」没关系，所以设置项、权限申请、相机权限一起清掉了，文档里相关说明也删了。
- **Lottie 自定义可视化效果**。依赖、视图、设置项全删；音乐可视化仍然用频谱。

如果你在用摄像头镜像——它没了。这是这一版最需要提前知道的一件事。

### 🔢 关于版本号

设置窗口重做 + 砍掉一整块功能，够得上 2.0.0。下一版如果只是修修补补，走 2.0.x。

## Notch Lyrics 2.0.0 (English)

The number jumps this far because this release **takes things away**, and because the
**settings window was rebuilt from scratch**. Removing counts as a major version.

### 🎛 Stats, in the notch

Four rings — CPU, GPU, memory, disk — over a 60-second network throughput trace (download
as the filled body, upload as the thinner line), with current rates and GPU memory
underneath. Sampling only runs while you are looking at it: a monitor that shows up in its
own CPU reading is the one failure mode worth designing against.

- Four colour schemes: monochrome, load, heat, alerts. Monochrome is the default, because a
  red ring beside "GPU 100%" reads like something is wrong — and that number only means the
  GPU had work in flight this second. It never gets coloured.
- You set what counts as a hot temperature or a full disk (Settings › Stats › Alerts).
- The trace's axis follows a fixed ladder, so it only moves when traffic crosses a step.
  Auto-scaling to the window peak rescaled the whole line every second and made it wobble.

### ⚡ Lyrics: faster when they exist, clearer when they don't

Almost every failure had the same shape: **a request timed out after 10 seconds while the
whole budget was 6**. One slow request ate the budget and the second source was never even
tried. That is where the log line "request timed out → no lyrics found" came from.

Now:

- **Both sources are asked concurrently**; whoever produces a verdict first wins. Total time
  is the slower of the two, not the sum.
- **A hard 3-second ceiling** — and hard it is: `URLRequest`'s timeout only covers "waiting
  for data after connecting", so it does nothing when DNS or the handshake stalls (measured:
  a request set to 2.5s took 4.5s to fail). We cancel it ourselves at the deadline instead.
- **A failed lookup is no longer cached.** One timeout used to become "no lyrics found" for
  the rest of the session, with no retry when you came back to the track.
- **The keyword search gets a reserved second.** Messy metadata — suffixes, "feat.", live
  takes — used to spend the whole 3-second budget on exact-signature probes, so the search
  that exists for exactly those tracks never ran.
- **Endpoint and proxy are configurable** (Settings › Media › Lyrics service). Point it at a
  mirror when the official address does not answer; leave the proxy empty to follow the
  system one.

While testing we found and fixed a bug that handed you **someone else's lyrics**: "Mesmer"
came back with "Mesmerizer"'s words. The root cause was weighting, not similarity — the
title was worth half the score, so a perfect artist and duration carried even a hopeless
title over the 0.6 line (lowering the similarity alone still scored 0.8). The title now has
to clear the bar on its own, and a fragment of a word no longer counts as the same song.

### 🎹 Instrumentals, decided more firmly

1.2.1 already recognised instrumentals, but only when the title said so. Piano pieces with no
clue in the title — "18 Pieces, Op. 72", "Lydian Harp", "Für Alina" — still fell back to
"No lyrics found".

Two more kinds of evidence now: **catalogue numbers** (`Op. 72`, `BWV 846`, `K. 485`,
`D. 899` are themselves a statement that this is a work with no words) and **genre** (once
every source comes back empty, we ask Apple Music what genre the track is — `Classical` is
the answer outright). Jazz, Electronic and Opera are deliberately excluded: vocals are far
too common in all three, and calling one of those "Instrumental" is worse than saying
"No lyrics found".

### 🖥 The settings window, rebuilt the way System Settings does it

- Every page opens with a centred icon–title–description card; every row leads with a small
  icon tile; separators start **where the text starts** instead of running under the icon.
  Same grammar as macOS System Settings.
- All the copy was rewritten, dropping lead-ins like "Beyond the microphone:" that say
  nothing, in favour of sentences you understand on first read.
- Three switches that **did absolutely nothing** are gone: the permanently greyed "Change
  media with horizontal gestures (not implemented yet)" on the Gestures page, "Extend hover
  area" under Advanced, and "Open shelf by default if items are present". Nothing had read
  them for a while.
- One panel now has exactly one name and one icon. The sidebar called it "Media" while the
  tab bar called it "Music", with a different glyph in each.

### 🗂 Choose which panels you keep

Settings › Appearance › Tabs: a switch each for Media, Shelf, Quick Note, Weather and Stats.

Switching one off only takes it out of the notch. The feature, its settings and its data stay
exactly where they were, so switching it back on restores what was there. At least one panel
always stays (the switch that would empty the bar is disabled), and if you switch off the
panel your home page points at, the home page moves to the first one still on.

### 🧹 Removed

- **The webcam mirror and the idle face animation** (an "additional feature" inherited from
  the original project). It has nothing to do with showing you the song you are playing, so
  the settings, the permission prompt and the camera entitlement went with it, along with the
  related documentation.
- **The Lottie custom visualiser.** Dependency, views and settings are gone; the music
  visualiser still uses the spectrogram.

If you were using the webcam mirror: it is gone. That is the one thing worth knowing before
you update.

### 🔢 About the version number

A rebuilt settings window plus a removed feature is enough for 2.0.0. If the next
release is just maintenance, it goes 2.0.x.
