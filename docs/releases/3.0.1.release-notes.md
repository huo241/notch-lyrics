# Notch Lyrics 3.0.1 更新说明

Notch Lyrics 3.0.1 (build 301) 修复了 3.0.0 中设置窗口在浅色模式下不显示所选背景质感的问题。此版本面向 macOS 14 Sonoma 及更高版本的 Mac。兼容性要求见 [项目仓库](https://github.com/huo241/notch-lyrics)。

如遇到未列入本说明的问题，请在标题与描述中写明完整版本号，格式如「3.0.1 (301)」。

## 设置

### 已修复

- 已修复：系统外观为浅色时，设置窗口渲染成纯白，`设置 › 外观 › 背景` 中的深黑、磨砂、透光三种质感均不生效。现在设置窗口固定使用深色外观，所选质感在任何系统外观下都会立即生效。 (2c5f00c)
