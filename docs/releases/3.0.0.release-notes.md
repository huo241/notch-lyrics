# Notch Lyrics 3.0.0 更新说明

Notch Lyrics 3.0.0 (build 300) 更新了刘海面板的形状与动画、背景质感与统计视图，并为 Apple Music 的部分专辑加入动态封面。此版本面向 macOS 14 Sonoma 及更高版本的 Mac，动态封面需搭配 Apple Music 作为播放源。兼容性要求见 [项目仓库](https://github.com/huo241/notch-lyrics)。

如遇到未列入本说明的问题，请在标题与描述中写明完整版本号，格式如「3.0.0 (300)」。

## 背景

### 新增

- 现在可以在 `设置 › 外观 › 背景` 中选择深黑、磨砂或透光三种质感，默认磨砂。 (15b9b53)
- 现在可以从正在播放的封面提取三色色板，并在面板左侧铺开柔光；黑白封面没有色板，不显示散光。 (15b9b53)

### 废弃

- 「灯光效果」开关已废弃。改用 `设置 › 外观 › 背景` 中的质感选项。 (15b9b53)

## 标签栏

### 新增

- 现在可以让五个标签均分标签栏的可用宽度。 (08b0d92)

### 已修复

- 已修复：展开态顶边横穿菜单栏图标，看起来像把状态图标切成了两段。 (94d0ebd)
- 已修复：面板收窄后，五个标签被中间的刘海黑块盖住。 (94d0ebd)
- 已修复：窄面板下标签图标之间的空隙不足。 (f4e8039)

## 动画

### 新增

- 现在可以用统一的开合曲线展开和收起面板，宽度和高度同时到位且没有过冲。 (15b9b53)
- 现在可以用 0.22 秒的淡入淡出切换标签页，不带缩放。 (15b9b53)
- 现在可以让手势拖动期间的进度按指针位置 1:1 更新，松手后才回弹。 (15b9b53)

### 已修复

- 已修复：面板展开动画结束后，开场动画开始前出现明显停顿。 (15b9b53)
- 已修复：一次状态变更被两层动画事务包裹时，面板各部分沿不同曲线运动并先后停住。 (15b9b53)

## 动态封面

### 新增

- 现在可以在 Apple Music 目录中的部分专辑播放动态封面，其余曲目保留静态封面。 (15b9b53)
- 现在可以在目录 ID 无法命中时，按专辑名和歌手搜索目录作为兜底。 (15b9b53)
- 现在可以按曲目缓存查询结果，包括「无动画资源」的负结果。 (15b9b53)
- 现在可以在 `设置 › 外观 › 播放器` 中关闭动态封面播放，默认开启。 (15b9b53)

### 已知问题

- 在某些情况下，本地导入的曲目可能不播放动态封面，静态封面照常显示。

  **绕行办法：** 改用 Apple Music 串流版本播放该曲目。

## 日历

### 废弃

- 日历标签页入口已废弃。改用 macOS 自带的「日历」应用查看日程。 (15b9b53)

## 设置

### 新增

- 现在可以在设置窗口侧栏底部看到版本号与发布代号 Kiso。 (15b9b53)
- 现在可以在设置窗口中使用深色背景材质与半透明侧栏。 (15b9b53)

### 已修复

- 已修复：设置窗口标题栏露出桌面，窗口顶部出现一条亮带。 (15b9b53)

## 统计

### 新增

- 现在可以用四个环显示 CPU、GPU、内存和磁盘占用率，数字写在环内。 (15b9b53)
- 现在可以在第二行直接读取当前上下行速率。 (15b9b53)
- 现在可以调整温度过高与磁盘空间不足的告警阈值。 (15b9b53)

### 废弃

- 60 秒网络吞吐曲线已废弃。改用第二行的实时上下行速率读数。 (15b9b53)
- 统计视图的配色选项已废弃。改用固定的四色索引。 (15b9b53)
