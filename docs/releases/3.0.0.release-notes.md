## Notch Lyrics 3.0.0「Kiso」

### 板子窄了一点，顶边不再压菜单栏

- 展开宽度从 640pt 收到 **580pt**。顶边收短，不再横穿菜单栏图标；肩部造型撤掉，
  下缘圆角放大到 32pt——展开时是一块干净的深色板，不是一个被切成两半的刘海。
- 五个标签均分可用宽度，图标再收一档，英文界面下不再有被中间黑块切断的标签。
- **动画全部统一**：开合走 0.30 秒有界曲线，宽和高同一时刻到位，没有过冲和拖尾；
  切页是 0.22 秒淡入淡出；手势拖动 1:1 跟手，只有松手才回弹。暂存器保留自己原有的交互曲线。

### 背景从开关变成三选一

原来的「灯光效果」开关换成了「质感」：**深黑 / 磨砂 / 透光**，默认磨砂，
所以升级后看到的基本还是你熟悉的板子。

- 深黑保留一点材质感；磨砂是系统磨砂玻璃；透光让封面颜色从左侧漫过面板。
- 颜色来自**正在播放的封面**：从封面取样、按色相归并，铺成三团柔光。
  黑白封面取不到色板，就没有散光——不是缺效果，是没内容可散。
- 三档是同一块板的不同质感，不叠加特效；底部渐变继续保住状态带白字的对比度。

### 部分专辑会动起来

Apple Music 目录里有些专辑带动态封面。现在播到这类专辑时，刘海里放的是动态封面，
其他曲目照旧是静态图。

- 先用 AppleScript 拿到的目录 ID 直查；本地导入的曲目对不上目录，就按「专辑 + 歌手」
  搜索并打分，分数不够宁可放弃——**配错专辑比没有动画更糟**。
- 查询结果（包括「这张没有动画」）按曲目缓存；网页播放器令牌按过期时间缓存，
  不会每切一首歌都去拉一次。
- 设置 › 媒体 ›「Animated cover art」默认开，可关。这需要 Apple Music 作为播放源。

### 统计：只留一眼能读的数

上一版的 60 秒网络曲线删掉了——一条带面积的曲线更像是装饰，而不是速度。
现在只有四个环（CPU / GPU / 内存 / 磁盘，数字写在环里）和一行上下行速率读数。

- 每个指标一个固定色当索引（珊瑚 / 紫 / 天蓝 / 薄荷），颜色不从壁纸取，也不表示负载高低。
- 红色只说一件事：这项真出问题了。磁盘空间真低时环变红；温度过高只让那行细节变红；
  **GPU 100% 永远不会红**——那是这一秒它有活干，不是报警。
- 「形状 / 配色」选项一并去掉，设置里只留告警阈值：多热算热、磁盘多满算满。
- 采样只看你在看的时候：切走标签就停，不让统计面板自己贡献 CPU 占用。

### 日历先不上线

侧栏里的日历入口暂时拿掉，代码原样留着；要恢复时只需把入口加回去。

### 版本号旁边多了个名字

设置窗口侧栏底部会显示「3.0.0 Kiso」。**Kiso 只是这一版的代号，只用来显示**，
不写进 Sparkle 或系统解析的版本字段，更新检查照旧按数字版本走。

## Notch Lyrics 3.0.0 (English) — “Kiso”

### A narrower slab, and a top edge that stays clear of the menu bar

- The open panel goes from 640 pt to **580 pt**. Its top edge no longer runs across the
  menu bar icons, the shoulder styling is gone, and the lower corners open up to 32 pt:
  a clean dark slab rather than a pinched notch.
- The five tabs share the available width evenly and their icons shrink one notch, so no
  label gets cut in half by the notch in English either.
- **One animation language throughout**: open/close is a bounded 0.30 s curve in which
  width and height settle together, with no overshoot and no long tail; panel switches
  cross-fade in 0.22 s; gestures track the pointer 1:1 and only spring back on release.
  The shelf keeps its own interaction curve.

### Background: one choice instead of a switch

The old lighting-effect switch becomes **Deep / Frosted / Clear**, with Frosted as the
default — so the panel you see after updating is essentially the one you already know.

- Deep keeps a little material feel; Frosted is the system frosted glass; Clear lets the
  artwork's colour wash across the panel from the left.
- The colour comes from **the cover that is playing**: sampled, bucketed by hue, and laid
  out as three soft pools of light. A black-and-white cover yields no palette, so there
  is no scatter — not a missing effect, just nothing to scatter.
- These are three finishes of the same slab, not stacked effects. The bottom gradient
  still holds white status text at readable contrast.

### Some albums move now

A few albums in the Apple Music catalogue ship animated cover art. When one is playing,
the notch plays it; every other track keeps its still image.

- The AppleScript catalogue ID is tried first. Locally imported tracks have an ID that
  does not resolve in the catalogue, so we search by album and artist and score the
  result — if it does not clear the bar, we stop. **The wrong album is worse than no
  animation.**
- Results, including "this album has no animation", are cached per track. The web
  player token is cached until expiry instead of being fetched on every track change.
- Settings › Media › "Animated cover art" is on by default and can be turned off.
  This needs Apple Music as the playback source.

### Stats: only what you can read at a glance

The 60-second network trace from the last release is gone — a filled curve read as
decoration more often than as speed. What remains is four rings (CPU, GPU, memory, disk,
with the number inside each) and a single line of download/upload rates.

- Each metric has one fixed hue as a key (coral / violet / sky / mint). It is never
  sampled from the wallpaper and never encodes load.
- Red means exactly one thing: this reading is in trouble. The disk ring turns red only
  when space is genuinely low; a hot part colours only its detail line; **GPU at 100%
  never turns red** — that is work in flight, not an alarm.
- The shape and palette switches are gone. Settings keeps only the alert thresholds:
  how hot is hot, and how full is full.
- Sampling runs while the tab is visible and stops when you leave it, so the monitor
  does not show up in its own CPU reading.

### Calendar stays off for now

The sidebar entry is hidden. The code is untouched, so bringing it back is a one-line change.

### A name next to the version number

The settings sidebar now reads “3.0.0 Kiso” at the bottom. **Kiso is a display-only
codename** — it never reaches the version fields Sparkle or macOS parse, so update
checks still follow the numeric version.
